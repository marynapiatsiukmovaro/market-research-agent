# WOW FACTOR ANALYSIS SKILL

## Evaluate
- First impression strength: would a stranger say "whoa, what is that?"
- Curiosity generation: does it make people want to know more?
- Transformation visibility: is before/after clear and dramatic?
- Emotional reaction: does it trigger desire, relief, or surprise?
- Visual uniqueness: does it stand out from generic products?
- Shareability: would someone tag a friend or save the ad?

## Wow-Factor Signals (High)
- Visible transformation in under 5 seconds
- Unexpected mechanism or design
- Solves embarrassing or very common problem
- Creates "I need this" reaction before price is shown
- Strong before/after dynamic

## Wow-Factor Signals (Low — reconsider)
- Product looks like everything else in the category
- Benefit requires explanation to understand
- No visual demonstration possible
- "Nice to have" rather than "need this now"
