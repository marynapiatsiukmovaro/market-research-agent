# FOUNDER TASTE MEMORY

Marina's personal quality bar for products. This file overrides raw scoring when there is a conflict.
Read this file every session alongside scoring-system.md.

## What Marina Responds To — Strong YES

These traits consistently produce products Marina finds compelling:

- **Visible, obvious transformation** — you can see the result in 2–3 seconds. No explanation needed.
- **Strong emotional hook on first impression** — "I need this" or "this solves my problem" instantly
- **Clear paid traffic angle** — obvious how to make a 15-second video that stops the scroll
- **Specific real pain** — not vague wellness, but: hair loss, neck pain, puffy eyes, poor posture
- **Premium feel at accessible price** — $49–69 that looks like a $150 product
- **Proven market via premium brand** — if a $200+ brand advertises it heavily, a $59 generic can win
- **Multi-audience product** — same product, 3-4 different buyer groups = more scalable

## What Marina Rejects — Clear NO

- **Too generic / commodity** — if it's on every Amazon page and looks like 50 others, skip
- **Weak visual hook** — needs a paragraph to explain the value
- **Low perceived value** — looks cheap, feels cheap, even if price is in range
- **Requires customer education** — if buyer needs to research before buying, it won't survive cold traffic
- **Obvious saturation** — everyone is already selling it, major brands dominate
- **Vague wellness claims** — "improves circulation" without a specific, visible result
- **71-score products with HIGH saturation warning** — these are borderline and risky; flag but do not push

## Calibration Rule

Founder taste is a calibration layer above numerical scoring.
A product that scores 74 but feels strong by these criteria → worth flagging for review.
A product that scores 78 but feels generic → flag as "Maybe, low conviction."

The goal is not hitting the score threshold. The goal is finding products Marina will be excited to test.
