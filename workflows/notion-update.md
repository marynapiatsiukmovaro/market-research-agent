# NOTION UPDATE WORKFLOW

For each accepted product (score 65+), create one Notion database entry.

## Required Fields
- Product Name (title)
- Category (select)
- Score (number, 0–100)
- Recommendation (select: High Priority / Worth Testing / Medium Potential)
- Problem Solved (text)
- Emotional Trigger (text)
- Why It May Work In Ads (text)
- Price Range Signal (select: Fits $39–79 / Too Cheap / Too Expensive)
- Competitor Ad Activity (checkbox + platform text)
- Creative Angles Count (number)
- Saturation Level (select: Low / Medium / High / Extreme)
- Supplier Availability (text: Alibaba/AliExpress availability)
- Source (text: where found)
- Date Added (date)
- Status (select: Not started / In progress / Done)

## Formatting Rules
- Keep all fields concise — scannable in under 10 seconds
- No long paragraphs in Notion entries
- Use tags/selects for filtering capability
- Always fill Score and Recommendation fields

## Priority
High Priority products (85+) → flag with colored tag in Notion.
