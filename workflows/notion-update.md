# NOTION UPDATE WORKFLOW

For each accepted product (score 65+), create one Notion database entry with two parts:
1. **Database properties** (fields in the table view)
2. **Page body** (internal card — opened when clicking the row)

---

## Part 1 — Database Properties (Table Fields)

| Field | Value |
|-------|-------|
| Title | Product name |
| Category | Beauty / Health / Home / Fitness / Kitchen / Pet / Tech / Other |
| Score | 0–100 |
| Recommendation | High Priority / Worth Testing / Medium Potential / Needs Verification / Rejected |
| Price | Actual retail price in $ |
| Price Range | Fits $39-79 / Too Cheap / Too Expensive |
| Problem Solved | 1 sentence max |
| Emotional Trigger | 1–3 words |
| Why It May Work | 2–3 bullet points |
| Competitor Ads | Checkbox (yes/no) |
| Ad Platform | Meta / TikTok / Both / Organic only |
| Creative Angles | Number (e.g. 4) |
| Saturation | Low / Medium / High / Extreme |
| Supplier | Short feasibility note (e.g. "Available on Alibaba") |
| Ad Link | Direct URL to ad or original source |
| Social Link | TikTok / Instagram profile or post URL |
| Store Link | URL of store/site where product is sold |
| Supplier Link | Alibaba / AliExpress listing URL (if found) |
| Notes | Any extra observations |
| Source | Platform where found (e.g. "TikTok Ads Library") |
| Date Added | Today's date |
| Status | Not started / In progress / Done |

### Source Verification Rule
- Both **Ad Link** + **Store Link** present → Recommendation as scored
- Only one link present → acceptable, note which is missing
- Both missing → set Recommendation to **"Needs Verification"** regardless of score
- Never invent or guess URLs — only real, working links

---

## Part 2 — Page Body Template (Internal Card)

This is what you see when you click open a product row. Structure:

```
## [Recommendation] — Score: [XX]/100

**Saturation:** [Low/Medium/High/Extreme] | **Category:** [X] | **Price:** $[XX]

---

### Problem & Trigger
**Problem Solved:** [1 sentence]
**Emotional Trigger:** [1–3 words]

---

### Why It May Work In Ads
- [Hook / visual angle]
- [Audience fit]
- [Impulse-buy factor]

### Creative Angles ([X] total)
1. [e.g. Problem/Solution]
2. [e.g. Transformation / Before-After]
3. [e.g. Social proof / UGC reaction]

---

### Market Evidence
**Competitor Ads:** [Yes / No / Organic only] — [Platform]
**Ad Volume:** [1–20 early / 20–100 growing / 100+ saturated]

---

### Source Links
- **Source / Ad:** [URL]
- **Store / Where It Sells:** [URL]

⚠️ If either link is missing → "Needs Verification"

---

### Notes
[Any additional observations, risks, or opportunities]
```

---

## Formatting Rules
- Recommendation + Score + Saturation always at the top — instant signal
- No long paragraphs
- 🔥 in title for High Priority (85+)
- ⚠️ in title for Needs Verification
