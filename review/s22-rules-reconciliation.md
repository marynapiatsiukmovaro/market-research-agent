| `methods/*` (api · card-contract · scripts · pipeline) | **английский** | технические, обращены к коду/скриптам |
| **ANALYSIS CREED** | **английский, ДОСЛОВНО** | 🔴 твой авторский текст (S16), красная линия — не переписывать/не переводить |

**Единственное исключение из «один файл — один язык»: CREED-блок внутри русского `rules.md` остаётся английским.**
Он — цитата авторского текста под красной линией. Два варианта, реши:
- **(A) [рекомендую]** CREED остаётся английским дословно, ниже — русский пункт «читается как есть, это душа».
- **(B)** добавить русский ПЕРЕВОД рядом с английским (English — канон, русский — глосса для скорости чтения),
  но переводить твой авторский текст = осознанная правка, нужно твоё ОК на формулировки перевода.
