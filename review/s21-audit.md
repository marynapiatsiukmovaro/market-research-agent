## Часть 3 — reach-обвал на th_s21_b1 (ПЕРВИЧНАЯ гипотеза «прокси» ОПРОВЕРГНУТА → см. Часть 5)

> ⚠️ **Эта часть сохранена как хроника ошибочного вывода.** Я сначала решил «прокси-IP сгорел» — НЕВЕРНО. Контроль (Часть 5) доказал: причина в ЧИСЛЕ ЗАПРОСОВ моего кода, не в прокси. Marina была права. Оставляю разбор, чтобы видеть, где я ошибся: одиночный заход через прокси работал, я принял это за «IP под челленджем», а надо было прогнать СТАРЫЙ код на тех же данных (он дал 89.6%).

**Факт:** прогон энричера на 250 магазинах (визиты 5 740–6 379) → **reach 47.6%** (119 из 250), приёмка **STOP**. 131 магазин: «site loads, no parseable products». count 250==250 OK, cur_null 0 — то есть НЕ счёт и НЕ валюта.

**Причина (проверено, RULE 4a):** прокси-IP `63.88.222.123` попал под Cloudflare-челлендж Shopify по ходу прогона. Доказательство:
- все 131 manual-магазина сейчас отдают «Your connection needs to be verified»;
- магазины, которые открылись В ЭТОМ ЖЕ прогоне (oceaniamaui, twnty-two), СЕЙЧАС тоже за стеной;
- контроли из b2 (learnplay, moluk), которые я не трогал и которые открывались дни назад, — тоже за стеной;
- `sh_proxy_check` → PROXY_OK (IP жив, подключается) — то есть прокси не упал, у него испортилась репутация у Shopify.

**Это НЕ правки S21.** По числу запросов они нейтральны (полка по смыслу — даже меньше). Первые ~119 магазинов прошли на чистом IP, потом стену подняли.

**Сигнатура (по чек-листу RULE 30):** быстро + низкий reach (493 с, 6 воркеров) = запросы отбиваются мгновенно заглушкой, НЕ медленная деградация throttle. Это репутация IP, а не перегруз.

**Что делать (RULE 14 — без паники, креды не менять):** IP надо дать остыть / iProyal ротирует эндпоинт. Чанк переэнричить позже; файл на месте, но недействителен. **В анализ на нём не идти.**

**Побочная находка:** когда главная магазина = challenge-страница, магазин помечается «manual / no parseable products», а `homepage_blocked` не ставится (для unreachable проверка `is_placeholder` не доходит). То есть «заблокирован ботвол» и «нет товаров» сейчас неотличимы в карточке. Мелкий дефект, вторичен к самому IP.
