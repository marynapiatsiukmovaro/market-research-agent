## Strategic takeaways (for the Pro-plan dumps, Shopify + WooCommerce)

1. **Niche-fit is a first-order filter.** "Heavy" niches (trade/materials = HI; accessory/food/service = Dogs) structurally yield ≈0 white-label-impulse winners no matter the visits band. **Weight dumps toward CONSUMER-impulse subcats** (the Nursery profile: real pain + camera-demoable + impulse + cheap white-label).
2. **The winner visits-zone is NICHE-DEPENDENT — never field-filter by visits.** Nursery winners sat DEEP (v363–447); Cats winners sat ONLY top (v≥1020); Dogs top. So we must read the WHOLE gradient per niche (RULE 24). Visits = ordering for pacing, never a gate.
3. **Best analogues to Nursery to try next:** baby/toddler-adjacent, sleep/soothing, safety, pet-CARE-with-a-real-mechanism (not accessories), wellness-with-camera-proof, problem-solving home gadgets (a beautiful filter on a tap-type, not "home improvement materials").
4. **WooCommerce = a 2nd independent universe (4.26M vs Shopify 2.89M).** Often self-hosted / fewer big brands → verify the enricher (`/products.json`, `/meta.json`) behaves the same before a giant dump; the audience/store-profile may differ from Shopify.
5. **Throughput model (Marina S14):** ~2,500 stores/session × 3 sessions/day ≈ 7,500/day → ~200k/month → ~400k "juicy" stores over 2 months. Pick the juiciest filters (consumer subcats + the right visit-bands per niche) since we can export EVERYTHING but analyse a slice.
