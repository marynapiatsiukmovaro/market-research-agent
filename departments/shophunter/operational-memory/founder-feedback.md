## Calibration signals (distilled — apply in future ShopHunter scoring)

🟢 **Marina KEEPS / APPROVES:** stylish + modern design · real pain-solver · health/wellness TREND (OroMilk = only Approved) ·
strong hooks / eye-catching · seasonal is OK **if** the pain is real (shoe dryers = Consider).

🔴 **Marina REJECTS (overrides commerce signals):**
- **"No clear wow yet"** — the #1 killer. **Convergence / revenue / multi-seller do NOT override missing wow.**
  → The titanium cutting board was REJECTED *despite* ×3-store convergence + strong revenue. I had over-weighted convergence.
- **"Low perceived value"** / **"weak economics"** — useful-but-cheap-feeling products (CoolClip, Jar Genie).
- **"Not priority category now"** — founder category-priority overrides a strong signal (titanium boards).
- **"Saturated + weak perceived effectiveness"** (Elevayr nursing pillow).

**KEY LESSON for SH-5+:** in deep-scoring, **wow + perceived value + Marina's category priority outrank convergence/
revenue/commerce proof.** A strong commercial signal with no wow = Reject. Lead candidate selection with the WOW + taste
read (from the live description), not the convergence count. Surface borderline ones for her — but don't oversell convergence.
