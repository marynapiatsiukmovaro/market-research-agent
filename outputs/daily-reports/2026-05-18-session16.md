## Session Learnings

**Critical discovery:** Offer/promo-phrase keywords are a confirmed dead class for DTC physical product discovery ($39-99). 867 advertisers → 0 reportable products. These phrases attract retail seasonal promotions, jewelry, apparel, supplements — not cold-traffic DTC operators.

**Technical note:** "%" symbol in FB Ads Library search URL breaks percent-encoding → 0 results. Use word alternatives ("half off" not "50% off").

**Correct performance signal class:** outcome/pain phrases ("say goodbye to", "game changer") — NOT price/offer phrases. S15 baseline: ~1 reportable per 370 advertisers for outcome phrases. S16: 0 per 867 for promo phrases.
